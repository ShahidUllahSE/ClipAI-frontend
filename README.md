# ClipAI Frontend

React + Vite + TypeScript UI for ClipAI.

## Setup

```bash
npm install
npm run dev
```

Runs on Vite (default `http://localhost:5173`). Proxies `/api` and `/uploads` to the backend at `http://localhost:4000`.

Copy `.env.example` to `.env` if you need `VITE_API_BASE_URL`.

## Scripts

- `npm run dev` — local UI
- `npm run build` — production build
- `npm run preview` — preview build
